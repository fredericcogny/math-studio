# Math Studio workspace rules

- Work only with files inside this repository. Never request or access files elsewhere.
- Never read global Git, SSH, cloud, browser, or editor credentials.
- Keep learner identities anonymous. Do not add names, dates of birth, schools, contact details, or other identifying information to tracked files.
- Treat `content/lessons` as reviewed educational source material. Keep exercises deterministic unless a task explicitly introduces an LLM-backed path.
- Keep English as the primary language. Add French translations for technical terms in lesson vocabulary metadata.
- Preserve alignment with the official French curriculum, then label content beyond it as `stretch` or `olympiad`.
- Use `npm run check` before considering code changes complete.
- Do not commit, push, alter remotes, or change GitHub settings unless the user explicitly requests it.
- Do not weaken Antigravity workspace isolation, terminal sandboxing, or the CLI Bubblewrap sandbox.
